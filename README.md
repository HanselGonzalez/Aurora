# 🩺 Aurora - Guía de Elegibilidad Anticonceptiva

Aurora es una aplicación móvil nativa para Android diseñada para asistir a profesionales de la salud y usuarios en la consulta rápida de los criterios médicos de elegibilidad para el uso de métodos anticonceptivos. 

Basada en directrices médicas estandarizadas, la aplicación evalúa qué métodos son seguros de usar dependiendo de las patologías preexistentes del paciente.

## 🚀 Funciones Principales

* **Filtro Clínico Inteligente:** Permite a los usuarios seleccionar patologías (ej. Hipertensión) y sub-patologías específicas para recibir una lista filtrada de métodos anticonceptivos.
* **Sistema de Clasificación Oficial:** Muestra de forma clara la escala de recomendación (del 1 al 4), desde "Uso en cualquier circunstancia" hasta "No se debe usar el método".
* **Rueda Interactiva Digital:** Integra una representación visual y táctil de los criterios médicos para una consulta rápida e intuitiva, replicando la experiencia de las herramientas físicas de salud.
* **Diseño Intuitivo y Accesible:** Interfaz limpia pensada para consultas rápidas en entornos clínicos.
