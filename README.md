# 🩺 Aurora - Contraceptive Eligibility Guide

Aurora is a native Android mobile application designed to assist healthcare professionals and users in quickly consulting the medical eligibility criteria for contraceptive use. 

Based on standardized medical guidelines, the app evaluates which methods are safe to use depending on the patient's pre-existing conditions.

## 🚀 Main Features

* **Smart Clinical Filter:** Allows users to select specific pathologies (e.g., Hypertension) and sub-pathologies to receive a filtered list of suitable contraceptive methods.
* **Official Classification System:** Clearly displays the recommendation scale (from 1 to 4), ranging from "Use method in any circumstances" to "Method not to be used".
* **Digital Interactive Wheel:** Integrates a visual and tactile representation of the medical criteria for a quick and intuitive consultation, replicating the experience of physical healthcare tools.
* **Intuitive & Accessible Design:** Clean interface built for fast consultations in clinical environments.

## 🛠️ Tech Stack

This project was built using modern Android development practices:

* **Language:** Kotlin
* **Navigation:** Jetpack Navigation Component
* **User Experience:** Core SplashScreen API for a seamless startup
